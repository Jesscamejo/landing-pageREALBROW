# Real Brow · Landing page

Página web del estudio de cejas **Real Brow**: técnicas, galería de fotos y videos, sobre mí, preguntas frecuentes y reservas por WhatsApp.

## Archivos

```
index.html   ← toda la página
imagenes/    ← tus fotos (portada, retrato, antes y después)
videos/      ← tus videos
```

## Cómo poner tus datos

Abre `index.html` y busca la parte que dice **"TUS DATOS — edita solo esta parte"**. Ahí puedes cambiar:

- **ESTUDIO**: número de WhatsApp (con código de país, sin + ni espacios), Instagram, dirección y horario.
- **FOTOS**: tu foto de portada y tu foto para "Sobre mí".
- **SERVICIOS**: nombre, descripción, duración y precio de cada técnica.
- **GALERÍA**: tus fotos y videos. Sube el archivo a `imagenes/` o `videos/` y escribe su ruta en `archivo`, por ejemplo `"imagenes/microblading-1.jpg"`.

El texto de **Sobre mí** se edita directamente en la sección marcada con ✏️.

## Reservas

El formulario arma un mensaje con el nombre, la técnica, la fecha y el horario, y lo abre en WhatsApp listo para enviar al número del estudio.
